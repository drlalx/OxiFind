Mockup areaegui / eframe building block
Menu bar and drop-downsTopBottomPanel::top + egui::MenuBar, ui.menu_button, ui.checkbox, nested sub-menus
Search field and togglesTextEdit::singleline with hint_text and focus on start, ui.selectable_label / toggle_value for modes, ComboBox for filter presets
Type filter chipsui.horizontal with selectable_label styled via Frame rounding
Volume sidebarSidePanel::left (resizable, toggled from View menu), CollapsingHeader per section
Result tableCentralPanel + egui_extras::TableBuilder with body.rows virtualization, clickable headers for sorting, Response::context_menu per row
Status barTopBottomPanel::bottom, labels fed from WorkerResponse messages
Theme / zoomctx.set_visuals (dark / light), ctx.set_zoom_factor

Size and date-modified columns require size/timestamp metadata in the index, which is not collected yet. Menu entries map to existing features where available (sorting, open, show in folder); the rest are candidates for later milestones.
